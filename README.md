# juki.space — organizer

React + Vite + Supabase, pronto para Cloudflare Pages **sem Wrangler**.

## Cloudflare Pages
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: `/`
- Environment variables:
  - `VITE_SUPABASE_URL`
  - `VITE_SUPABASE_PUBLISHABLE_KEY`

## Supabase
Execute `supabase/schema.sql` no SQL Editor antes do login.

O app já possui login/cadastro, dashboard, tarefas, projetos e calendário conectados ao Supabase.
